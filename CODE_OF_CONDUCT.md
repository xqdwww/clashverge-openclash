# Contributor Code of Conduct

Contributors must communicate respectfully, avoid harassment and discriminatory
language, accept constructive review, and never disclose another person's
private information or configuration data.

Maintainers may remove contributions or restrict participation when behavior
threatens people, project safety, or confidentiality. Report conduct or security
concerns through the repository's private GitHub Security Advisory form.
Reports will be handled as confidentially as reasonably possible and conflicts
of interest will be avoided.

This policy applies in repository spaces and when representing the project in
public spaces.
